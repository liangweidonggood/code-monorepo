# net-service-monorepo 编码规范

> 适用范围: 全部子项目。目标：SonarQube 零警告。checkstyle 零警告零错误,pmd零错误

## 工具

checkstyle插件，pmd插件，sonarqube插件，写完代码后必须要通过这三个插件的验证

加类抑制和修改规则文件必须通过用户同意

## 1. 格式

### 1.1 大括号

`if` / `for` / `while` **必须使用大括号**，即使只有一行。

```java
// ❌
if (x > 0) return x;
// ✅
if (x > 0) {
    return x;
}
```

### 1.2 命名


| 元素 | 规范           | 示例                           |
| ---- | -------------- | ------------------------------ |
| 类名 | UpperCamelCase | `ProtocolFrameDecoder`         |
| 方法 | lowerCamelCase | `compute()`                    |
| 常量 | UPPER_SNAKE    | `MAGIC_NUMBER`                 |
| 包名 | 小写.分隔      | `com.lwd.netservicenetty.core` |

## 2. 常量抽取标准

**只提取协议规范级别的共享常量**。自解释的值不要抽。

```java
// ✅ 协议共享常量 — 多处引用，值有明确协议含义
public static final byte MAGIC_NUMBER = (byte) 0xFE;
public static final int MAX_FRAME_LENGTH = 1024;
public static final int MSG_HEARTBEAT = 0x03;

// ✅ 本地有明确业务含义的阈值 — 当前类内使用，注释清楚
private static final int LOW_WATER_MARK = 512 * 1024;   // 512KB
private static final int HIGH_WATER_MARK = 1024 * 1024; // 1MB

// ❌ 不要抽 — 自解释的常识值，提取反而更难读
b.option(ChannelOption.SO_BACKLOG, 1024);       // 1024 = TCP backlog，常识
pipeline.addLast(new IdleStateHandler(60, ...)); // 60 = 秒，单位已在参数中
ChannelTrafficShapingHandler(0, 2L*1024*1024, 1000); // 2MB/s，1000ms
```

**判断标准**: 如果常量值需要另一个文件才能看到，且值本身在上下文中自解释 → 不要抽。

---

## 3. 注释

- 类和方法必须有 Javadoc
- 类中的属性必须有注释
- Pipeline 装配必须有流程注释
- 关键算法逻辑必须有行内注释
- record类中的属性使用行尾注释
- 不要删注释
- 注释必须使用中文

---

## 4. 配置

- 端口、线程数、超时、日志级别 → `application.yaml`
- 协议常量 → `ProtocolConstants.java`
- 禁止硬编码 IP / 端口 / 路径

---

## 5. 禁止事项

- `import *` 通配符
- `System.out` / `System.err`
- `printStackTrace()`（用 `log.error("...", e)`）
- I/O 线程中执行阻塞操作
- 单行 if 省略大括号
- 把 `1024`、`60`、`2*1024*1024` 这种常识值提取为常量
