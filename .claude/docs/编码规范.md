# net-service-monorepo 编码规范

> 适用范围: 全部子项目。Java 部分约束最严格，Go/Rust 参考精神。

---

## 1. 格式规范

### 1.1 大括号

`if` / `for` / `while` 必须使用大括号，即使只有一行。

```java
// ❌ 禁止
if (x > 0) return x;

// ✅ 正确
if (x > 0) {
    return x;
}
```

### 1.2 魔法值

字面量提取为命名常量，放在所属类的顶部，或在协议定义中集中管理。

```java
// ❌ 禁止
pipeline.addLast(new ChannelTrafficShapingHandler(0, 2L * 1024 * 1024, 1000));
b.bind(8888);

// ✅ 正确
private static final long READ_LIMIT_BPS = 2 * 1024 * 1024;
private static final int CHECK_INTERVAL_MS = 1000;
pipeline.addLast(new ChannelTrafficShapingHandler(0, READ_LIMIT_BPS, CHECK_INTERVAL_MS));
```

### 1.3 配置外化

端口、线程数、日志级别、超时时间等运行参数一律通过 `application.yaml` 注入。

```java
// ❌ 禁止
b.bind(8888);

// ✅ 正确
b.bind(config.port());
```

## 2. 命名规范

| 元素 | 规范 | 示例 |
|------|------|------|
| 类名 | UpperCamelCase | `ProtocolFrameDecoder` |
| 方法名 | lowerCamelCase | `computeFrame()` |
| 常量 | UPPER_SNAKE_CASE | `MAGIC_NUMBER` |
| 包名 | 小写点分隔 | `com.lwd.netservicenetty.core` |
| 测试类 | 被测类名 + Test | `CommonResponseCodecTest` |

## 3. 代码结构

### 3.1 文件组织

```java
package ...

import ...       // 无通配符 *

/**
 * 类 Javadoc — 说明职责
 */
public class Xxx {
    // 1. 常量
    private static final int MAX = 100;

    // 2. 成员变量
    private final Xxx dependency;

    // 3. 构造函数

    // 4. 公开方法

    // 5. 私有方法
}
```

### 3.2 POJO

必须使用 `record`，不可变，字段带 Javadoc。

```java
/**
 * 心跳 — 链路保活
 * <p>
 * Body: [终端号(7B BCD)] + [流水号(2B)] + [状态位(1B)] = 10 字节
 */
public record Heartbeat(
        String terminalId,  // 终端号，14位BCD数字
        int seqNo,          // 流水号
        byte statusFlags    // 状态位
) implements TcpPacket {
}
```

## 4. 服务端/客户端配置分离

- 服务端和客户端**端口必须不同**
- 客户端应独立于服务端运行（不同 JVM）
- 开发阶段可通过配置切换: `netty.client.enabled=true/false`

```yaml
netty:
  server:
    port: 8888
  client:
    enabled: true        # 开发阶段可开启，生产必须 false
    host: localhost
    port: 8889           # 必须和服务端不同
```

## 5. 协议常量集中管理

协议中出现的固定值（消息类型码、魔数、长度限制等）放在 `TcpPacket` 接口或专用常量类中。

```java
public final class ProtocolConstants {
    private ProtocolConstants() {}

    public static final byte MAGIC_NUMBER = (byte) 0xFE;
    public static final int MAX_FRAME_LENGTH = 1024;

    // 消息类型
    public static final int MSG_COMMON_RESPONSE = 0x00;
    public static final int MSG_REGISTRATION_REQUEST = 0x01;
    public static final int MSG_AUTH_REQUEST = 0x02;
    public static final int MSG_HEARTBEAT = 0x03;
    public static final int MSG_LOCATION_REPORT = 0x10;
    public static final int MSG_ALARM_REPORT = 0x11;
    public static final int MSG_DATA_TRANSMISSION = 0x12;
    public static final int MSG_COMMON_RESPONSE_SERVER = 0x80;
    public static final int MSG_REGISTRATION_RESPONSE = 0x81;
    public static final int MSG_IMMEDIATE_REPLAY = 0x82;
    public static final int MSG_REMOTE_CONFIG = 0x83;
}
```

## 6. 禁止事项

- `import *` 通配符导入
- `System.out.println` / `System.err.println`（用 SLF4J）
- `catch (Exception e) { e.printStackTrace(); }`（用 `log.error("...", e)`）
- 在 I/O 线程中执行阻塞操作
- 单行 if 省略大括号
- 硬编码端口/IP/路径
